# Flight Search Validator

This is a Maven Java 17project.  
It implements and tests the `runFlightSearch()` method inside the `FlightSearch` class.

---

### Files
- pom.xml  
- src/main/java/flight/FlightSearch.java  
- src/test/java/flight/FlightSearchRunTests.java  

---

### Eclipse Setup
1. Import -> Existing Maven Project  
2. Right click FlightSearchRunTests.java -> Run As -> JUnit Test
